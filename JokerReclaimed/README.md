# Joker Reclaimed · 조커 복원소

Steamodded용 조커 천장 모드입니다. 필요 없는 조커를 찢어 영구 조각을 모으고, 상점에서 해금된 원하는 조커를 복원합니다. 원본 게임의 15개 언어를 지원합니다.

## 사용법

1. 보유 조커를 클릭하고 **찢기**를 선택합니다. 확인 후 조커가 사라지고 조각을 받습니다.
2. 상점의 **조커 복원하기**를 누릅니다. **F7**로도 열 수 있습니다.
3. 등급을 고르고 카드 또는 가격 버튼을 누릅니다.
4. 스티커와 에디션을 선택한 후 최종 조각·달러 가격을 확인하고 복원합니다.

찢기는 판매가 아닙니다. 판매대금, 판매 조커 발동, 판매 통계, 신록의 잎의 판매 조건을 발생시키지 않습니다. 실제 카드 그림과 에디션을 유지한 채 두 갈래의 톱니 모양으로 찢어지고, 원본 종이 소리·파티클·소멸 효과로 마무리됩니다. 원본의 모션 감소 설정을 켜면 갈라지는 움직임을 생략합니다. 이터널 조커와 다른 모드가 파괴 불가로 보호한 조커는 찢을 수 없습니다. 확인 창은 Mods → Joker Reclaimed → Config에서 끌 수 있습니다.

## 가격

| 등급 | 찢어서 얻는 조각 | 복원 기본 조각 | 기본 달러 가격 |
|---|---:|---:|---|
| 일반 / Common | 1 | 10 | 원래 구매가 |
| 희귀 / Uncommon | 3 | 30 | 원래 구매가 |
| 레어 / Rare | 7 | 60 | 원래 구매가 |
| 레전더리 / Legendary | 20 | 100 | $10 |

원래 구매가는 기본 에디션의 현재 상점 가격이며 할인권과 런의 가격 인상을 반영합니다.

| 옵션 | 달러 가격 | 추가 조각 |
|---|---|---:|
| 렌탈 | **구매가를 $1로 대체** | 0 |
| 부패 | **구매가를 $1로 대체** | 0 |
| 이터널 | **구매가를 $2로 대체** | 0 |
| 포일 | 변경 없음 | 5 |
| 홀로그래픽 | 변경 없음 | 10 |
| 폴리크롬 | 변경 없음 | 20 |
| 네거티브 | 변경 없음 | 50 |

**스티커는 달러 가격만 대체합니다. 등급별 기본 조각 비용은 항상 유지합니다.** 렌탈+부패는 $1, 렌탈+이터널은 $2입니다. 부패와 이터널은 원본 규칙대로 동시에 선택할 수 없습니다. 해당 조커가 호환되지 않는 스티커는 선택할 수 없습니다. 에디션은 한 종류만 선택합니다.

예: 일반+렌탈+폴리크롬 = **조각 30개 + $1**, 레전더리+렌탈+이터널+네거티브 = **조각 150개 + $2**.

## 저장

조각 지갑은 모든 런과 프로필에서 공유됩니다. 일반 런·시드 런·챌린지에서 같은 지갑을 사용하며 게임 종료 후에도 유지됩니다. 돈은 현재 런의 돈만 사용합니다. 신용 카드의 허용 부채 한도도 반영합니다.

Windows 저장 경로:

```text
%APPDATA%\Balatro\joker_reclaimed\wallet-a.json
%APPDATA%\Balatro\joker_reclaimed\wallet-b.json
```

두 파일을 **함께 백업**하세요. 각 변경은 새 스냅샷을 기록하고 다시 읽어 검증한 뒤 적용합니다. 하나가 손상되면 남은 정상 스냅샷으로 복구합니다. 둘 다 손상되면 지갑을 0으로 덮어쓰지 않고 거래를 중단합니다. 기록된 거래는 런의 적용 기록과 대조하여 이어하기에서 중복 지급·중복 구매를 막고, 중단된 런 저장을 복구합니다. 저장 폴더를 수동으로 과거 버전으로 돌리는 행위까지 완벽하게 방지하는 서버형 재화 시스템은 아닙니다.

모드 폴더를 업데이트하거나 제거해도 지갑 파일은 유지됩니다. 복원한 조커를 제공하는 다른 모드가 없으면 미완료 거래 복구가 보류되므로 그 모드를 다시 활성화하세요.

## 설치와 배포

Lovely 및 Steamodded 1.0.0 베타 이상이 필요합니다. **Balatro 1.0.1o / Steamodded 26.829.0 / Lovely 0.10.0** 환경을 대상으로 개발했습니다.

ZIP 안의 `JokerReclaimed` 폴더를 그대로 `%APPDATA%\Balatro\Mods\` 아래에 넣고 게임을 재시작하세요. 최종 경로가 `Mods\JokerReclaimed\JokerReclaimed.json`이면 올바릅니다. 모드 자체에는 Lovely 패치가 없으며 Steamodded의 함수 훅을 사용합니다.

모드 조커는 등록된 카드 중 해금되어 있고 숨김 처리되지 않은 카드를 자동으로 표시합니다. 챌린지에서 금지된 카드는 제외합니다. 커스텀 등급은 기본적으로 레어 가격을 사용하며 `balance.lua`의 `custom_rarities`에서 명시적으로 설정할 수 있습니다. 독자적인 상점 UI가 표준 버튼 영역을 없앤 경우 F7로 복원소를 열 수 있습니다.

## 테스트 치트

Mods → **Joker Reclaimed → Config → 테스트 치트 활성화**를 켜세요. 런 안에서 **왼쪽 Ctrl + 왼쪽 Shift + F8**을 누르면 **조각 1000개와 $100**을 받습니다. 조각은 실제 지갑에 영구 저장됩니다. 치트는 기본적으로 꺼져 있고, 해금 조건을 바꾸지는 않습니다.

## 수치 변경

`balance.lua`에 찢기 보상, 등급별 복원 가격, 스티커 달러 대체가, 에디션 추가 조각, 치트 지급량·키가 모두 모여 있습니다. 변경 후 게임을 다시 시작하세요. 화면 옵션을 저장하는 `config.lua`와 영구 지갑은 별개입니다.

커스텀 등급 예:

```lua
custom_rarities = {
    mymod_epic = {scraps = 12, price = 80, dollars = 9},
},
```

## 언어와 화면

한국어, 영어, 일본어, 중국어 간체·번체, 독일어, 프랑스어, 스페인어(스페인·중남미), 포르투갈어(브라질), 이탈리아어, 인도네시아어, 러시아어, 네덜란드어, 폴란드어를 지원합니다. 게임에서 선택한 언어를 따르며 조커 이름과 설명은 원본/해당 조커 모드의 번역을 사용합니다.

복원소의 카드 미리보기는 각 영역의 가로·세로 중앙에 고정됩니다. 목록과 선택 화면의 미리보기에만 이 정렬을 적용하며 카드에 커서를 올리면 원본 설명창이 표시됩니다.

기본 API 참고: [Steamodded 공식 문서](https://docs.smods.dev/). 이미지 에셋은 **Forge의 GPT Image 2.5 Sunburst (`gpt_image_25_sunburst`)**로 비공개 생성했습니다. 원본 Balatro의 실제 UI 색상 팔레트에 맞춰 32×32 / 64×64 아틀라스로 변환했으며, 원본 게임 이미지 파일은 배포에 포함하지 않습니다.
