# 검증 결과

## 공개 1.0.0

치트를 제거한 최종 코드로 LuaJIT 구문 22개 파일, 경제·저장 276개 항목, 15개 언어의 765개 문자열·자리표시자 검사를 통과했습니다. 사용자 요청에 따라 15개 언어로 실제 화면 75장을 촬영했고, 이 화면으로 가이드 이미지 15장을 제작했습니다. [캡처 방법과 원본](../docs/CAPTURES.md)을 참고하세요. 이 촬영은 전체 게임 회귀 테스트가 아닙니다.

공개 버전 번호는 사용자 요청대로 1.0.0입니다. 아래 1.0.1/1.0.2는 외부에 배포하지 않은 개발 중 버전 번호이며, 기존 실행 검사 기록을 구분하기 위해 남겼습니다.

## 개발 중 기록

이 폴더의 이전 검증용 PNG는 로컬 자료이며 Git에는 포함하지 않습니다. 배포용 새 스크린샷은 `docs/images`에 있습니다.

1.0.2 수정: 치트 옵션·단축키·지급 함수를 제거했습니다. 게임 실행 없이 LuaJIT 구문 검사 22개 파일, 경제·저장 검사 276개 항목, 15개 언어의 765개 문자열 및 자리표시자 검사를 통과했습니다.

1.0.1 수정: 복원 버튼의 영구 비활성화 원인을 수정했습니다. 아래 실행 검증 결과는 1.0.0 기준이며, 1.0.1은 사용자 요청에 따라 게임을 실행하지 않고 구문·코드 검사만 수행했습니다.

2026-10-12, Balatro 1.0.1o / Steamodded 26.829.0 / Lovely 0.10.0에서 검증했습니다. 설치된 DVPreview와 QuickRestart도 함께 로드했습니다. 실제 프로필과 분리된 `Balatro-JRC-QA` 저장 폴더를 사용했습니다.

- LuaJIT 구문 검사: 22개 파일 통과.
- 경제·저장 단위 검사: 276개 항목 통과.
- 15개 언어 번역: 795개 문자열 및 자리표시자 검사 통과.
- 실제 게임 실행: [qa-report.json](qa-report.json)의 1,383개 항목 통과.

실행 검사에는 해금 필터, 구매와 찢기, 판매대금 없음, 중복 지급 차단, 달러만 바뀌는 스티커 가격, 네거티브 슬롯, 이터널 보호, 버튼과 확인창, 이전 저장에서의 거래 복구, 디스크 재읽기, 다음 런의 조각 유지가 포함됩니다.

15개 언어 각각 목록·선택 화면을 렌더링했습니다. 원본 폰트가 모든 모드 문자열의 문자를 지원하는지 검사했고, 카드의 목표 좌표뿐 아니라 실제 표시 좌표의 가로·세로 중심, 원근 셰이더에 의한 추가 변위가 없는지도 확인했습니다. `qa-locale-<언어>-catalogue.png`, `qa-locale-<언어>-options.png`가 각 화면입니다.

이전 화면 파일은 로컬에서만 보관합니다. 공개 문서는 [새 한국어 가이드](../docs/languages/ko.md)를 참고하세요.

다른 모든 외부 모드 조합을 검증한 것은 아닙니다. 조커의 이름·설명 번역은 원본 및 해당 조커를 제공하는 모드에 따릅니다.
